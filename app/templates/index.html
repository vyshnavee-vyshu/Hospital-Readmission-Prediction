About

Academic machine-learning workspace for hospital readmission modeling.

Project Overview

This web application supports dataset inspection, preprocessing, model comparison, and estimated binary readmission scoring on a local machine.

Objective

Provide a transparent workflow from tabular hospital records to evaluated classifiers, without presenting outputs as clinical advice.

Methodology

  1. Dataset
  2. Preprocessing
  3. EDA
  4. Feature Engineering
  5. Model Training
  6. Evaluation
  7. Prediction

Dataset

Upload any CSV with a binary or diabetes-style readmission target. Common column names include readmitted, readmission, or target.

Supported target values: 0/1, Yes/No, True/False, and NO / >30 / <30 (NO maps to 0; both 30-day groups map to 1).

Machine Learning Models

Logistic Regression, Decision Tree, Random Forest, XGBoost, and a calibrated linear Support Vector Machine. Metrics are computed on a held-out test split.

Technology Stack

FastAPI, Uvicorn, Pandas, NumPy, Scikit-learn, XGBoost, Joblib, SQLite, HTML, CSS, JavaScript, Chart.js.

System Architecture

A single local web server serves the interface and JSON APIs. Models and the preprocessor are stored as Joblib files. Prediction history is stored in SQLite.

Limitations

Results depend on the uploaded sample, missingness, class balance, and default hyperparameters. High-cardinality diagnoses are frequency-encoded. This is not an external clinical validation study.

Healthcare Disclaimer

This software is for academic demonstration only. It is not a medical device and must not be used for diagnosis, triage, discharge planning, or patient-level care decisions.
